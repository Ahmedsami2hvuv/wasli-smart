# منصة «وصلي» (Wasli Smart) 

منصة عراقية حديثة للتسوق من المتاجر المحلية وطلب المنتجات مع تسهيل وتتبع التوصيل السريع للمنازل، مع تركيز خاص واهتمام استثنائي بمتاجر وبساتين قضاء **أبي الخصيب** في محافظة البصرة.

---

## مميزات المنصة

- **هوية بصرية عراقية راقية**: تصميم حديث يعتمد الأزرق الموثوق والأزرق السماوي ولمسات من الأصفر الدافئ بدون استخدام أي رموز تعبيرية (Emojis).
- **تجربة استخدام عربية كاملة (RTL First)**: دعم أصيل للغة العربية والاتجاه من اليمين إلى اليسار مع خط Cairo العصري.
- **قسم خاص بمتاجر قضاء أبي الخصيب**: إبراز تمور البرحي الفاخرة، حلويات نهر خوز، أسماك ومسكوف البصرة وبساتين الخصيب.
- **سلة مشتريات تفاعلية وسريعة**: تمكن الزبون من مراجعة المنتجات، زيادة الكميات، وإتمام الطلب مع خيار الدفع عند الاستلام.
- **تصفح فوري ومريح**: تصنيف المتاجر وفلترتها بالبحث المباشر.
- **تجربة هاتف استثنائية (Mobile-First)**: شريط تنقل سفلي يتيح التصفح والطلب بيد واحدة بكل سهولة.

---

## البنية التقنية (Tech Stack)

- **إطار العمل**: [Next.js](https://nextjs.org/) (App Router) مع TypeScript.
- **تنسيق الواجهة**: [Tailwind CSS](https://tailwindcss.com/).
- **الأيقونات**: [Lucide React](https://lucide.dev/).
- **الاستضافة**: مهيأ للربط المباشر مع Vercel.

---

## التشغيل المحلي

لتشغيل السيرفر المحلي للتطوير:

```bash
npm run dev
```

ثم افتح المتصفح على: `http://localhost:3000`

لبناء المشروع للإنتاج والتحقق من الجاهزية:

```bash
npm run build
```

## التوجيهات الدائمة للتطوير

يرجى مراجعة ملف `AGENTS.md` في جذر المشروع للاطلاع على كافة معايير الهوية البصرية، مهارات التصميم، وقواعد الأتمتة المعتمدة.
