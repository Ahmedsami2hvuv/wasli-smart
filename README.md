# منصة «وصلي» (Wasli Smart) 

منصة عراقية حديثة للتجارة الإلكترونية والتسويق الذكي بنظام التسمية البيضاء (White-Label) بدون رأس مال، تمكّن الشباب من أن يصبحوا **تجاراً** بامتلاك **متاجرهم الخاصة** والبيع للزبائن في كافة محافظات العراق، مع تولي المنصة لعمليات التخزين والشحن والتحصيل.

---

## المفاهيم والمصطلحات المعتمدة في المنصة

1. **التاجر**: كل شخص ينشئ متجراً خاصاً به عبر منصة وصلي للبدء بالبيع وتحقيق الأرباح.
2. **متجر التاجر**: المتجر الإلكتروني الخاص بالتاجر برابطه المخصص (`/s/[code]`) والموجه لزبائنه.
3. **صفحة التاجر**: لوحة التحكم الخاصة بالتاجر (`/merchant`) لإدارة أرباحه، مبيعاته، أسعار البيع، وطلب سحب الرصيد.
4. **صفحة المدير (لوحة الأدمن)**: لوحة الإدارة والتحكم الشاملة الخاصة بالمدير (`/waahhlstor`) لإدارة المنتجات والمخزون والطلبات.

---

## المبدأ الأساسي: خصوصية متجر التاجر والتسمية البيضاء (White-Label Policy)

- **حماية مبيعات وأرباح التاجر 100%**: عند مشاركة رابط المتجر مع الزبائن، يظهر المتجر باسم التاجر وعلامته وهوامش أرباحه فقط.
- **منع ظهور اسم المنصة للزبون**: يُمنع منعاً باتاً ظهور اسم «وصلي» أو شعارها أو روابط عودة إلى موقع المنصة داخل متجر التاجر أو صفحة المنتج أو صفحة الدفع أو صفحة تأكيد الطلب، لضمان عدم مغادرة الزبون لمتجر التاجر.
- **أرقام طلبات محايدة**: توليد أرقام طلبات بنسق محايد يحمي خصوصية المصدر (مثل `ORD-10492`).

---

## مميزات المنصة

- **هوية بصرية عراقية راقية**: تصميم حديث يعتمد الأزرق الموثوق والأزرق السماوي ولمسات من الأصفر الدافئ بدون استخدام أي رموز تعبيرية (Emojis).
- **تجربة استخدام عربية كاملة (RTL First)**: دعم أصيل للغة العربية والاتجاه من اليمين إلى اليسار مع خط Cairo العصري.
- **تغطية شاملة لكافة محافظات العراق**: شحن وتوصيل فوري لجميع مدن ومحافظات العراق (18 محافظة).
- **سلة مشتريات وتجربة شراء سلسة**: واجهة بسيطة تمكن الزبون من إتمام طلبه مباشرة بالدفع عند الاستلام.
- **صفحة تاجر ذكية ومتطورة**: متابعة المبيعات والأرباح وإدارة أسعار البيع وإشعارات الطلبات الفورية عبر تيليجرام.
- **تجربة هاتف استثنائية (Mobile-First)**: تصفح سهل ومريح لكافة المستخدمين.

---

## البنية التقنية (Tech Stack)

- **إطار العمل**: [Next.js](https://nextjs.org/) (App Router) مع TypeScript.
- **تنسيق الواجهة**: [Tailwind CSS](https://tailwindcss.com/).
- **الأيقونات**: [Lucide React](https://lucide.dev/).
- **الاستضافة**: مهيأ للربط المباشر مع Vercel.

---

## التشغيل المحلي

لتشغيل السيرفر المحلي للتطوير:

```bash
npm run dev
```

ثم افتح المتصفح على: `http://localhost:3000`

لبناء المشروع للإنتاج والتحقق من الجاهزية:

```bash
npm run build
```
