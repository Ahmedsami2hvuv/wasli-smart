# منصة «وصلي» (Wasli Smart) 

منصة عراقية حديثة للتجارة الإلكترونية والتسويق بالعمولة والدروب شيبينغ بدون رأس مال، تمكّن الشباب والمسوقين من إنشاء متاجرهم الخاصة والبيع للزبائن في كافة محافظات العراق، مع تولي المنصة لعمليات التخزين والشحن والتحصيل.

---

## المبدأ الأساسي: خصوصية متجر التاجر والتسمية البيضاء (White-Label Policy)

- **حماية مبيعات وأرباح المسوّق 100%**: عند مشاركة رابط المتجر مع الزبائن، يظهر المتجر باسم المسوّق وعلامته وهوامش أرباحه فقط.
- **منع ظهور اسم المنصة للزبون**: يُمنع منعاً باتاً ظهور اسم «وصلي» أو شعارها أو روابط عودة إلى موقع المنصة داخل متجر المسوّق أو صفحة المنتج أو صفحة الدفع أو صفحة تأكيد الطلب، لضمان عدم مغادرة الزبون للمتجر.
- **أرقام طلبات محايدة**: توليد أرقام طلبات بنسق محايد يحمي خصوصية المصدر.

---

## مميزات المنصة

- **هوية بصرية عراقية راقية**: تصميم حديث يعتمد الأزرق الموثوق والأزرق السماوي ولمسات من الأصفر الدافئ بدون استخدام أي رموز تعبيرية (Emojis).
- **تجربة استخدام عربية كاملة (RTL First)**: دعم أصيل للغة العربية والاتجاه من اليمين إلى اليسار مع خط Cairo العصري.
- **تغطية شاملة لكافة محافظات العراق**: شحن وتوصيل فوري لجميع مدن ومحافظات العراق (18 محافظة).
- **سلة مشتريات وتجربة شراء سلسة**: واجهة بسيطة تمكن الزبون من إتمام طلبه مباشرة بالدفع عند الاستلام.
- **لوحة تحكم ذكية للمسوقين**: متابعة المبيعات والأرباح وإدارة أسعار البيع بسهولة.
- **تجربة هاتف استثنائية (Mobile-First)**: تصفح سهل ومريح لكافة المستخدمين.

---

## البنية التقنية (Tech Stack)

- **إطار العمل**: [Next.js](https://nextjs.org/) (App Router) مع TypeScript.
- **تنسيق الواجهة**: [Tailwind CSS](https://tailwindcss.com/).
- **الأيقونات**: [Lucide React](https://lucide.dev/).
- **الاستضافة**: مهيأ للربط المباشر مع Vercel.

---

## التشغيل المحلي

لتشغيل السيرفر المحلي للتطوير:

```bash
npm run dev
```

ثم افتح المتصفح على: `http://localhost:3000`

لبناء المشروع للإنتاج والتحقق من الجاهزية:

```bash
npm run build
```
